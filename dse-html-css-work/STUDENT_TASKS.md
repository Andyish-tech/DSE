# Student assignment — Build a professional landing page
INTANGO TSS | DSE Cohort 2 | Trainer: Fidèle NDAYISHIMIYE

Scenario: A fictional learning centre needs a homepage advertising three courses. Build it using HTML and CSS only. You may change the theme to a shop with product cards.

1. Create index.html, style.css and images/. Link your stylesheet and use the supplied local illustrations.
2. Build a header with a brand and four navigation links pointing to sections.
3. Build a hero with one h1, a short explanation, a course link and an image with meaningful alt text.
4. Create three professional cards with an image, category, title, description and course details. Use article and a shared CSS class. Details must open through native details/summary.
5. Add an about section and footer with classroom contact information and working navigation.
6. Use Flexbox or Grid, consistent spacing, readable colours, rounded cards and a hover effect.
7. Adapt the layout for desktop, tablet and phone. Avoid horizontal scrolling.
8. Explain your HTML structure, one layout rule, a media query and a relative image path.

## Assessment /100
Semantic structure and content: 20; header and hero: 20; reusable cards: 20; responsive layout: 20; footer and working links: 10; accessibility and explanation: 10.

## Check before submission
- Open the page without an internet connection: all images and CSS load.
- Test at 375px, 768px and 1440px screen widths.
- Click each navigation link and expand each course description.
- Use Tab and Enter to operate the links and details.
- Check image alt text, heading order and visible keyboard focus.
- Submit the complete folder as a ZIP. Be ready to explain your own changes.
